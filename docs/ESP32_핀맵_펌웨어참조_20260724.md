# R큐브 메인보드 — ESP32-S3 핀맵 & 펌웨어 참조 설명서

- **대상 MCU**: ESP32-S3-WROOM-1-**N16R2** (16MB Flash + 2MB Quad PSRAM), refdes **U40**
- **근거 회로도**: `HW설계/회로도/20260724/rcube_mainboard_20260724.kicad_sch` (최종본)
- **역할**: BLE/CAN 통신, 20–50Hz 키프레임 생성, MicroPython 미션 실행, 모터제어보드(STM32G4) 오케스트레이션
- **작성일**: 2026-07-24

> ⚠️ **안전 최우선**: 부팅 직후 (1) `PWR_HOLD`를 High로 잡아 전원 래치, (2) `MC_GATE_EN`을 "모터 차단" 안전상태로 두는 것을 **가장 먼저** 수행하세요. 상세는 §6 참조.

## 3. 통신 인터페이스 상세

### 3.1 CAN (TWAI)
- `IO4=TX`, `IO5=RX` → TJA1042T/3 트랜시버. ESP32 내장 **TWAI**(Classic CAN 2.0, 최대 1Mbps).
- `IO6=CAN_STB`: 트랜시버 대기 제어. **부팅 시 Low로 구동(정상모드)**. (R28 10k 풀다운으로 기본 정상)
- `IO7=CAN_TERM_EN`: **소프트웨어 종단**. 이 큐브가 버스 끝단이면 High로 120Ω 종단 활성. 노드ID/위치 로직과 연동.

### 3.2 모터제어보드(STM32G4) 인터페이스 — 인터보드 J110
- **제어평면 = UART**: `IO17=TX`, `IO18=RX` (UART1 또는 UART2 배정).
- `IO8=MC_FAULT`(IN): 모터보드 폴트 → 인터럽트로 즉시 감지 권장.
- `IO35=MC_GATE_EN`(OUT): 모터 게이트 인에이블 — **안전상태 관리 대상**(§6).
- `IO36=MC_BOOT0`(OUT) / `IO37=MC_nRST`(OUT, Active-Low): 모터보드 리셋·부트0 제어로 **STM32G4 펌웨어 업데이트 패스스루** 구현.

### 3.3 IMU (BMI088) — SPI
- 한 SPI 버스에 **CS 2개**: `IO10=CS_ACC`, `IO9=CS_GYR` (BMI088은 가속/자이로 다이가 분리).
- `IO11=MOSI`, `IO12=SCLK`, `IO13=MISO`. SPI2(FSPI) 호스트 권장, SPI 모드/속도는 BMI088 데이터시트 준수.

### 3.4 카메라 — SPI3 (JST GH 6P, J130)
- `IO39=SCLK`, `IO40=MOSI`, `IO41=MISO`, `IO42=CS`. **IMU와 별도 SPI 호스트** 사용.

### 3.5 USB (네이티브)
- `IO19=D−`, `IO20=D+` → ESP32-S3 내장 USB-Serial-JTAG/TinyUSB. 프로그래밍·로그·JTAG. **다른 용도로 전용하지 말 것.**

### 3.6 UART0
- `TXD0(GPIO43)`, `RXD0(GPIO44)` → 콘솔/시리얼 프로그래밍, 헤더 J101로 인출.

## 4. 주변장치 (LED / 부저 / 서보 / 센서)
- **LED** `IO38`: WS2812B ×3 데이지체인. RMT(또는 SPI) 드라이버. ⚠️ 5V 구동 LED에 3.3V 데이터라 VIH 마진 확인 필요(HW 검토항목).
- **부저** `IO14`: AO3400A 게이트 구동. LEDC PWM으로 톤 생성. 기본 Low(무음), R80 풀다운.
- **서보** `IO21`: RC 서보 신호(50Hz, 1–2ms 펄스). LEDC 또는 MCPWM.
- **외부센서** `IO15/IO16`: 범용 I/O(용도 펌웨어 정의). ADC2 사용 가능(단 Wi-Fi 동시 사용 시 ADC2 제약 주의).

## 5. 스트래핑 / 부팅 주의 (ESP32-S3)
ESP32-S3 스트래핑 핀: **GPIO0, GPIO3, GPIO45, GPIO46**. 리셋 순간 레벨이 부팅 모드를 결정합니다.

| GPIO | 넷 | 스트랩 기능 | 주의 |
|---|---|---|---|
| IO0 | BOOT_NET | 부팅 모드(Low=다운로드) | 평상 High. BOOT 버튼(SW41)으로 Low |
| IO3 | IO3 | JTAG 소스 선택 | 리셋 시 부정확한 레벨 금지 |
| IO45 | IO45 | VDD_SPI 전압 | 스트랩 상태 고정 필요 |
| IO46 | IO46 | ROM 메시지/부팅 | 리셋 시 Low 유지 권장 |

- **Flash/PSRAM**: N16R2는 **Quad** PSRAM이라 GPIO26–32만 내부 사용 → **GPIO33–37 자유**(그래서 IO35/36/37을 모터보드 제어에 쓰는 것이 유효). Octal(R8)이면 이 핀들이 막히니 부품 변경 시 주의.
- 스트래핑 핀은 부팅 후 일반 GPIO로 재사용 가능하나, **리셋 타이밍 레벨 충돌이 없도록** 외부 회로/펌웨어를 설계하세요.

## 6. 펌웨어 초기화 체크리스트 (안전 우선 순서)
1. **전원 래치**: 부팅 극초반에 `IO47(PWR_HOLD)=High` → STM6601 tON_BLANK(옵션 CA2B=1.4s) 안에 반드시. 실패 시 자동 전원차단(시큐어 스타트업).
2. **모터 안전상태**: `IO35(MC_GATE_EN)`을 **모터 차단** 값으로 우선 설정(+ HW 풀다운 권장). `IO37(MC_nRST)`로 필요 시 모터보드 리셋 유지.
3. **CAN 트랜시버**: `IO6(CAN_STB)=Low`(정상모드). `IO7(CAN_TERM_EN)`은 노드 위치에 따라 설정.
4. **버스/주변 초기화**: TWAI(IO4/5), UART-모터(IO17/18), SPI2-IMU(IO9–13), SPI3-카메라(IO39–42), LEDC-부저(IO14)/서보(IO21), RMT-LED(IO38), USB 네이티브.
5. **버튼 핸들러**: `IO48(PWR_INT)` 하강엣지 인터럽트로 "눌림 이벤트" 감지 → `IO2(PB_OUT)`로 hold 시간 측정(§7).

## 7. 전원버튼 상태머신 (SW50 / STM6601)
- **켜기**: OFF 상태에서 버튼 → STM6601이 전원 인가 → ESP32 부팅 → `PWR_HOLD=High` 래치.
- **동작 중 누름 감지**: `PWR_INT(IO48)` 인터럽트 발생 → 타이머 시작, `PB_OUT(IO2)`로 눌림 유지 측정:
  - **뗌 < 3초** → 연결모드 진입
  - **≥ 3초 유지** → 초기화 연결모드
  - **≥ 10초 유지** → `PWR_HOLD(IO47)=Low` 구동 → **강제 OFF**
- 참고: STM6601의 하드웨어 롱푸시(강제OFF/RST)는 SR핀을 +3V3_SB로 고정해 **비활성** 상태이므로, 위 3단 로직은 전적으로 펌웨어가 제어합니다.
